# Wantedly 開発者採用リサーチスキル

Wantedlyに掲載されている最新の開発者・エンジニア採用募集を調査し、構造化レポートとして出力する。

## 実行ワークフロー

### Phase 1: Web検索（複数クエリ必須・最低5クエリ）

以下のクエリを**すべて**実行し、幅広い求人を収集する:

**必須クエリ（毎回実行）:**
1. `site:wantedly.com エンジニア 募集 採用 2026`
2. `site:wantedly.com バックエンド エンジニア 募集`
3. `site:wantedly.com フロントエンド エンジニア 募集`
4. `site:wantedly.com エンジニア AI Cursor Claude 募集` ← AI活用企業を狙う
5. `site:wantedly.com エンジニア スタートアップ フルリモート 募集`

**追加クエリ（引数指定時）:**
- keywordが指定された場合: `site:wantedly.com {keyword} 開発者 採用`
- positionが指定された場合: `site:wantedly.com {position} エンジニア 募集`
- conditionsが指定された場合: `site:wantedly.com エンジニア {conditions}`

**検索のコツ:**
- 検索結果が少ない場合はクエリを変えて再検索する（最低3回は試行）
- `wantedly.com/projects/` のURLが実際の求人ページ。`/hiringeek/` は記事なのでスキップ
- 重複企業は除外し、多様な業界・規模の企業を優先

### Phase 2: 詳細情報収集（5〜10社、デフォルト7社）

検索結果からWantedlyの求人ページURL（`wantedly.com/projects/数字`形式）を特定し、WebFetchで各ページの詳細を取得する。

**各企業について以下の5項目を必ず収集する:**

1. **業界**: 企業の属するセクター（IT/SaaS、EdTech、クリエイティブPF等）。スラッシュ区切りで具体的なサブカテゴリまで記載。
2. **サービス内容**: **具体的なプロダクト名・サービス名を必ず記載**。「Webサービス開発」のような曖昧な記載は不可。例: 「pixiv、BOOTH、pixivFANBOX、VRoid等のクリエイター支援サービス」
3. **募集職種**: ポジション名に加え、**使用技術スタックを括弧内に記載**。例: 「バックエンドエンジニア（Go/Python）」「フロントエンドエンジニア（React/Next.js）」
4. **条件**: 雇用形態（中途採用/業務委託/新卒）、勤務形態（フルリモート/ハイブリッド/出社）、その他特記事項（副業OK、フレックス等）
5. **特徴**: **数値データを含む**特筆すべき点。例: 「登録ユーザー1億超、460名規模、グローバル展開」「創業5期目で200名規模」。AI活用（Cursor/Claude Code/ChatGPT等）の記載があれば必ず含める。

**収集時の注意:**
- 情報が取得できないページはスキップし、別の企業で補完する
- 架空のデータや推測は絶対に記載しない
- 企業名は正式名称を使用（株式会社を含む）
- 1社あたり最低3行以上の情報量を確保する
- WebFetchで404が返る場合は別URLで補完し、指定企業数を必ず確保

### Phase 3: トレンド分析（備考セクション用）

収集した全企業のデータ＋検索中に得た市場情報から以下の**4項目すべて**を分析し、「備考」セクションにまとめる:

1. **給与開示**: Wantedlyでの給与記載の慣行（通常は「スキル見合い」「応相談」で非公開が一般的）
2. **勤務形態**: フルリモート率、ハイブリッドの割合、特殊な勤務形態（海外勤務等）
3. **AI活用**: Cursor、Claude Code、ChatGPT、GitHub Copilot等のAIツール活用状況。求人票に記載がなくても、検索フェーズで得た情報を含める。「AI活用（Cursor、Claude Code、ChatGPT等）を推進する企業が増加傾向」等の全体トレンドも記載。
4. **技術スタック**: 主要な言語・フレームワークのトレンド（Go, Python, TypeScript, Ruby on Rails, React/Next.js/Vue.js等）

### Phase 4: 構造化レポート出力

以下の**正確なフォーマット**で出力する:

```
## Wantedly 直近の開発者採用募集リサーチ結果

### 1. [正式企業名]
- **業界**: [具体的なセクター/サブカテゴリ]
- **サービス内容**: [具体的プロダクト名を含む説明]
- **募集職種**: [ポジション名（使用技術スタック）]
- **条件**: [雇用形態、勤務形態、その他]
- **特徴**: [数値データを含む特筆点]

### 2. [正式企業名]
（...count数だけ繰り返し）

---

**備考**:
- Wantedlyでは給与・報酬の金額は非公開が一般的（「スキル見合い」等の記載が多い）
- [勤務形態に関する傾向]
- [AI活用に関する傾向]
- [技術スタックに関する傾向]

**リサーチ日時**: YYYY年MM月DD日
```

## 品質チェックリスト（出力前に必ず確認）

- [ ] 5〜10社（デフォルト7社）の情報が含まれている
- [ ] 各企業の5項目（業界/サービス内容/募集職種/条件/特徴）がすべて記載されている
- [ ] サービス内容に具体的なプロダクト名が含まれている（「Webサービス」等の曖昧表現はNG）
- [ ] 募集職種に使用技術が括弧内に記載されている
- [ ] 特徴に数値データ（従業員数、ユーザー数、設立年等）が含まれている
- [ ] 備考にトレンド分析が**4項目すべて**（給与/勤務形態/AI活用/技術スタック）含まれている
- [ ] AI活用に関する傾向が備考に明記されている
- [ ] 架空のデータが一切含まれていない
- [ ] リサーチ日時が記載されている
- [ ] すべて日本語で記載されている

## 注意事項

- Wantedlyの求人は頻繁に更新されるため、WebSearchとWebFetchで**最新情報**を取得すること
- 検索結果が少ない場合はクエリを変えて再検索する（最低3回は試行）
- ページが取得できない場合は別の企業で補完し、指定数を確保する
- 出力は必ず日本語
- Phase 1の年号は実行時の年に合わせること（2026→2027等）
