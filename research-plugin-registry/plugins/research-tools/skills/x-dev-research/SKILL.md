# X(Twitter) 開発者採用リサーチスキル

X(Twitter)上に投稿された最新の開発者・エンジニア採用情報を調査し、構造化レポートとして出力する。

## 実行ワークフロー

### Phase 1: Web検索（複数クエリ必須・最低5クエリ）

以下のクエリを**すべて**実行し、X上の採用情報を広範に収集する:

**必須クエリ（毎回実行）:**
1. `site:x.com エンジニア 募集 採用 2026`
2. `site:x.com OR site:twitter.com バックエンド エンジニア 採用 募集`
3. `site:x.com OR site:twitter.com フロントエンド エンジニア 採用 募集`
4. `site:x.com エンジニア 年収 採用 スタートアップ`
5. `site:x.com エンジニア AI 採用 Rust Go Python`

**追加クエリ（引数指定時）:**
- keywordが指定された場合: `site:x.com {keyword} エンジニア 採用`
- positionが指定された場合: `site:x.com {position} エンジニア 募集 採用`
- industryが指定された場合: `site:x.com エンジニア 採用 {industry}`

**検索のコツ:**
- X(Twitter)のURLは `x.com/ユーザー名/status/数字` 形式。この形式のリンクを優先
- 企業公式アカウント、採用アカウント、CTOや採用担当者のポストを対象とする
- 検索結果が少ない場合はクエリを変えて再検索する（最低3回は試行）
- 重複企業は除外し、多様な業界・規模の企業を優先
- リプライやRTではなく、オリジナルの採用ポストを優先

### Phase 2: 詳細情報収集（3〜10社、デフォルト6社）

検索結果からX(Twitter)の採用ポストURLを特定し、WebFetchで各ポストの詳細を取得する。
ポストから得られない情報は企業の公式サイト・採用ページも合わせて調査する。

**各企業について以下の5項目を必ず収集する:**

1. **業界**: 企業の属するセクター（ロボティクス/AI、SNS/テクノロジー、エンタメ/VTuber、DeFi/暗号資産等）。スラッシュ区切りで具体的なサブカテゴリまで記載。
2. **サービス内容**: **具体的なプロダクト名・サービス名を必ず記載**。「Webサービス開発」のような曖昧な記載は不可。例: 「人型ロボット開発（ARCHAX等）」「にじさんじ等VTuberプロジェクト運営」
3. **募集職種**: ポジション名に加え、**使用技術スタック/言語を括弧内に記載**。例: 「バックエンドエンジニア（Rust/C++/Go）」。複数職種がある場合はすべて記載。
4. **条件（年収）**: 年収レンジが公開されている場合は**必ず記載**。非公開の場合は「詳細は募集要項参照」と記載。ジュニア/ミドル/シニア等のレベル別があればすべて記載。
5. **出典**: X(Twitter)のポストURL（`https://x.com/ユーザー名/status/数字` 形式）

**収集時の注意:**
- X上の年収情報は貴重なデータなので、記載がある場合は必ず含める
- 情報が取得できないポストはスキップし、別の企業で補完する
- 架空のデータや推測は絶対に記載しない
- 企業名は正式名称を使用
- WebFetchで取得できない場合は別のアプローチ（企業名での再検索等）で補完し、指定企業数を確保

### Phase 3: 補足情報収集（参考データセクション用）

Phase 1-2の検索過程で見つかった以下の補足データを収集し、レポートに含める:

1. **参考年収データ**: OpenMoney、転職会議、Glassdoor等から得られた年収情報を表形式でまとめる
2. **新卒採用情報**: 新卒エンジニア採用を実施中の企業リスト（締切日があれば記載）
3. **市場トレンド**: 検索中に得られた採用市場のトレンド情報（技術スタック、リモート率、AI活用等）

## 注意事項

- X(Twitter)のポストは流動的なため、WebSearchで最新情報を取得すること

- 出力は必ず日本語
- Phase 1の年号は実行時の年に合わせること
- X(Twitter)とTwitter両方のドメインで検索すること
