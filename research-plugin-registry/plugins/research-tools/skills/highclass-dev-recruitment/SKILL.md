# ハイクラス開発者採用リサーチスキル

年収900万円以上のハイクラス開発者・PM採用募集を、複数の転職プラットフォームから横断的に検索し、構造化レポートとして出力する。

## 実行ワークフロー

### Phase 1: マルチプラットフォーム検索（最低8クエリ必須）

以下のクエリを**すべて**実行し、幅広いハイクラス求人を収集する。各プラットフォームで最低1クエリずつ実行する。

**必須クエリ（毎回実行）:**
1. `site:green-japan.com エンジニア 年収900万 採用 2026`
2. `site:doda.jp エンジニア 年収900万以上 募集`
3. `site:wantedly.com エンジニア ハイクラス 募集 CTO`
4. `site:mynavi.jp エンジニア 年収900万 転職`
5. `site:bizreach.jp エンジニア 年収1000万 求人`
6. `転職ドラフト エンジニア 年収900万 指名`
7. `ハイクラス エンジニア 年収900万以上 採用 PM EM 2026`
8. `エンジニア AI Cursor Claude 年収1000万 募集` ← AI活用高年収企業を狙う

**追加クエリ（引数指定時）:**
- positionが指定された場合: `{position} 年収900万以上 採用 求人`
- min_salaryが指定された場合: 上記クエリの「900万」を指定値に置換
- industryが指定された場合: `{industry} エンジニア ハイクラス 年収900万以上 求人`
- conditionsが指定された場合: `エンジニア 年収900万 {conditions} 求人`

**検索のコツ:**
- 検索結果が少ない場合はクエリを変えて再検索する（最低3回は試行）
- 各プラットフォームの求人ページURLパターンを把握:
  - Green: `green-japan.com/job/` 
  - doda: `doda.jp/DodaFront/View/JobSearchDetail/`
  - Wantedly: `wantedly.com/projects/数字`
  - ビズリーチ: `bizreach.jp/`
- 重複企業は除外し、多様な業界・規模・ポジションの企業を優先
- 年収900万未満の求人は除外する

### Phase 2: 詳細情報収集（5〜15社、デフォルト10社）

検索結果から求人ページURLを特定し、WebFetchで各ページの詳細を取得する。

**各企業について以下の5項目を必ず収集する:**

1. **業界**: 企業の属するセクター（IT/SaaS、AI、フィンテック、EdTech等）。スラッシュ区切りで具体的なサブカテゴリまで記載。
2. **サービス内容**: **具体的なプロダクト名・サービス名を必ず記載**。「Webサービス開発」のような曖昧な記載は不可。例: 「クラウド会計ソフトfreee、freee人事労務等のバックオフィスSaaS」「ABEMA、Ameba、タップル等のメディア・エンタメサービス」
3. **募集職種**: ポジション名に加え、**使用技術スタックを括弧内に記載**。例: 「バックエンドエンジニア（Go/Python/GCP）」「プロダクトマネージャー（toB SaaS）」「VPoE/EM（組織設計・採用戦略）」
4. **条件（年収）**: **年収レンジを必ず記載**。雇用形態（正社員/業務委託）、勤務形態（フルリモート/ハイブリッド/出社）、その他特記事項（副業OK、フレックス、SO付与等）。例: 「年収900万〜1500万、正社員、フルリモート可、副業OK」
5. **特徴**: **数値データを含む**特筆すべき点。例: 「ARR100億円突破、社員数800名、東証グロース上場」「累計調達額50億円、シリーズC、グローバル展開中」。AI活用（Cursor/Claude Code/GitHub Copilot等）の記載があれば必ず含める。

**収集時の注意:**
- 年収情報が明記されていない場合は「年収：要相談（ハイクラス求人サイト掲載）」と記載
- 情報が取得できないページはスキップし、別の企業で補完する
- 架空のデータや推測は絶対に記載しない
- 企業名は正式名称を使用（株式会社を含む）
- 1社あたり最低3行以上の情報量を確保する
- WebFetchで404が返る場合は別URLで補完し、指定企業数を必ず確保

### Phase 3: 市場トレンド分析（備考セクション用）

収集した全企業のデータ＋検索中に得た市場情報から以下の**5項目すべて**を分析し、「備考」セクションにまとめる:

1. **年収帯の傾向**: ハイクラス求人の年収レンジ分布（900万〜1200万が多い、PM/EMは1500万超も等）
2. **ポジション傾向**: 需要の高いポジション（バックエンド > フロントエンド、PM/EM需要増等）
3. **勤務形態**: フルリモート率、ハイブリッドの割合、特殊な勤務形態（海外勤務、ワーケーション等）
4. **AI活用**: Cursor、Claude Code、ChatGPT、GitHub Copilot等のAIツール活用状況。求人票に記載がなくても、検索フェーズで得た情報を含める。
5. **技術スタック**: 高年収求人で求められる主要な言語・フレームワーク・インフラのトレンド（Go, Python, TypeScript, Rust, Kubernetes, GCP/AWS等）

### Phase 4: 構造化レポート出力

以下の**正確なフォーマット**で出力する:

```
## 直近の開発者（エンジニア・PM）採用募集リスト

### 1. [正式企業名]
- **業界**: [具体的なセクター/サブカテゴリ]
- **サービス内容**: [具体的プロダクト名を含む説明]
- **募集職種**: [ポジション名（使用技術スタック）]
- **条件（年収）**: [年収レンジ、雇用形態、勤務形態、その他]
- **特徴**: [数値データを含む特筆点]

### 2. [正式企業名]
（...count数だけ繰り返し）

---

**備考**:
- 年収帯: [ハイクラス求人の年収レンジ傾向]
- ポジション: [需要の高いポジション傾向]
- 勤務形態: [フルリモート・ハイブリッド等の傾向]
- AI活用: [AIツール活用の傾向]
- 技術スタック: [高年収帯で求められる技術トレンド]

**リサーチ日時**: YYYY年MM月DD日
```

## 品質チェックリスト（出力前に必ず確認）

- [ ] 5〜15社（デフォルト10社）の情報が含まれている
- [ ] 各企業の5項目（業界/サービス内容/募集職種/条件(年収)/特徴）がすべて記載されている
- [ ] サービス内容に具体的なプロダクト名が含まれている（「Webサービス」等の曖昧表現はNG）
- [ ] 募集職種に使用技術が括弧内に記載されている
- [ ] 条件に年収レンジが明記されている（全企業で必須）
- [ ] 特徴に数値データ（従業員数、ARR、ユーザー数、調達額等）が含まれている
- [ ] 備考にトレンド分析が**5項目すべて**（年収帯/ポジション/勤務形態/AI活用/技術スタック）含まれている
- [ ] 年収900万未満の求人が混入していない
- [ ] 架空のデータが一切含まれていない
- [ ] 複数プラットフォーム（最低3つ）からの情報が含まれている
- [ ] リサーチ日時が記載されている
- [ ] すべて日本語で記載されている

## 注意事項

- 各プラットフォームの求人は頻繁に更新されるため、WebSearchとWebFetchで**最新情報**を取得すること
- 検索結果が少ない場合はクエリを変えて再検索する（最低3回は試行）
- ページが取得できない場合は別の企業で補完し、指定数を確保する
- 出力は必ず日本語
- Phase 1の年号は実行時の年に合わせること
- 年収情報は日本円で統一（万円単位）
